# ChatBot Builder

Create rule-driven chatbots directly in your browser, preview them live, and export as standalone JavaScript files. No backend required — everything runs client-side.

**Check It Out:** [ChatBot Builder -- https://rudycon55555.github.io/ChatBot-Creation-App/](https://rudycon55555.github.io/ChatBot-Creation-App/)

## Features
- ✨ Rule editor with Simple and JavaScript modes
- 🧪 Live chatbot preview
- 📥 Export bots as `.js` files
- 🎨 Modern, responsive UI
- 🔒 100% front-end, no backend needed
